# Plan de corrección de seguridad

## Incidente: posible exposición de credenciales

- Incidente: posible exposición de credenciales.
- Acción: retirar las credenciales del código.
- Acción adicional: rotar las credenciales afectadas.
- Prevención: usar variables de entorno o un gestor de secretos.
- Validación: comprobar que no queden credenciales expuestas.
